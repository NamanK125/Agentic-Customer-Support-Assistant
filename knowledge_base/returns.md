# Returns Policy

PulseNest has two return windows. Which one applies depends on whether you opened the item.

## Unopened items: 30 days
You can return an unopened item within 30 days of delivery for a full refund.

## Opened items that are not defective: 15 days
If you opened the BP-200, OX-02 or SC-03 and it is not defective, you can return it within 15 days of delivery. A 10% restocking fee is deducted from the refund.

## Opened thermometer (TH-01): not returnable
For hygiene reasons an opened TH-01 thermometer cannot be returned unless it is defective.

## Defective devices
If any device is defective, we replace it under warranty. A refund is given only if a replacement is out of stock.

## Care+ subscription
Care+ is not refundable. You can cancel anytime and cancellation takes effect at the end of your billing month.

## How to return
Start a return from the app or contact support with your order id. We will tell you whether the item is eligible and when the return window ends. After the item arrives at our warehouse it is inspected; see the refunds article for timing.

## Exceptions
Only a human support agent can approve exceptions to this policy. The assistant cannot waive the restocking fee or extend a return window.
